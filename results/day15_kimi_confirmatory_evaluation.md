## 1. 一句话结论

这次一次性确认实验**没有证明 Kimi v2 能可靠识别推荐模型主要依赖文字还是图片**。主指标 ITT 宏平均召回率为 **48.31%**，用户级聚类 bootstrap 95% CI 为 **41.64%–55.59%**；点估计低于“永远猜 text”的 50% 宏召回基线，区间也覆盖 50%。因此不能把开发集上的 72.02% 当作可泛化效果。

## 3. 预先指定的主分析（ITT）

| 指标 | 结果 |
|---|---:|
| 准确率 | 67.29% |
| 准确率用户聚类 bootstrap 95% CI | 63.56%–71.02% |
| text 召回率 | 70.44% |
| image 召回率 | 26.19% |
| **宏平均召回率（主指标）** | **48.31%** |
| **宏平均召回率用户聚类 bootstrap 95% CI** | **41.64%–55.59%** |
| 永远猜 text 的准确率 / 宏召回 | 92.88% / 50.00% |
| image 预测精确率 | 8.21%（11/134） |
| 高置信错误（置信度 ≥ 0.8） | 133/590 |

ITT 混淆矩阵如下；`invalid` 是 43 个永久失败：

| 真值 | 预测 text | 预测 image | invalid |
|---|---:|---:|---:|
| text | 386 | 123 | 39 |
| image | 27 | 11 | 4 |

普通准确率在这里容易误导，因为 text 占 92.88%。Kimi 频繁把 text 真值判成 image，却只正确找出 11 个 image 样本；所以它的总体准确率甚至低于“永远猜 text”，而类别平衡后的表现约等于随机强制二选一。

## 4. 次要与诊断性分析

仅看 547 个严格有效回答时，准确率为 72.58%，text/image 召回率为 75.83%/28.95%，宏平均召回率为 52.39%。这只是诊断性结果，不能替代 ITT 主结果，否则会产生幸存者偏差。

有效回答的平均自报置信度为 0.845，但全体样本中有 133 个高置信错误，说明自报置信度不能作为可靠性保证。模型声称的文字占比与连续干预强度之间 Spearman 相关为 −0.077，用户聚类 bootstrap 95% CI 为 −0.161–0.006；区间覆盖 0，未显示可泛化的单调对应关系。

## 5. 与开发集的关系

v2 在 80 条开发集上的 ITT 宏召回率为 72.02%，而未参与提示词开发的 590 条确认集为 48.31%。开发集只有 7 个 image 真值且被用于选择 v2，因此开发表现不能再被当作独立证据。按照冻结规则，本次结果不会触发 v3、重评分或选择性补跑；若未来改进提示词，必须作为新的探索阶段，并使用新的未见测试集验证。
